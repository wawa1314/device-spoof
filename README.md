# 改机型模块

KernelSU / Magisk 机型伪装模块，酷安@KNJ蛙。

## 功能

- **全局改机型**：改整机属性，所有应用都看到假机型
- **单应用改机型**：只改指定应用，其它应用读真机
- **批量配置**：一次给多个应用套同一个机型
- **系统应用可选**：支持伪装系统应用

## 特性

- 内置 2740 个真实机型模板，覆盖 24 个品牌
- 机型名直接显示完整名字（如 REDMAGIC 11 PRO+）
- 支持 KernelSU / APatch

## 使用

1. 刷入模块，重启
2. 打开 WebUI
3. 选模式（全局 / 单应用）
4. 选机型，套用
5. 目标应用划掉重开生效
