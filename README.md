# 改机型模块

KernelSU / Magisk 机型伪装模块，作者 酷安@KNJ蛙。

## 功能

- **全局改机型**：改整机属性，所有应用都看到假机型
- **单应用改机型**：只改指定应用，其它应用读真机
- **批量配置**：勾选多个应用，一次套同一个机型
- **系统应用可选**：自带应用也能伪装
- **机型指纹**：每个机型都带系统指纹，不会出现品牌与指纹矛盾

## 字段说明

| 字段 | 填什么 | 举例（小米 14） |
|---|---|---|
| model 型号 | 真实型号代码 | 23127PN0CC |
| device / product | 内部代号 | houji |
| marketname 市场名 | 机型全名 | Xiaomi 14 |
| fingerprint 指纹 | 按品牌格式生成 | Xiaomi/houji/houji:15/... |

型号用真实代码，是为了让酷安这类按型号比对机型库的应用能正常显示发帖机型尾巴；全名放市场名，devcheck 等看市场名的工具照常显示机型名。

## 使用

1. 刷入模块，重启
2. 打开 WebUI，选模式（全局 / 单应用）
3. 模板库搜机型点一下，参数自动填好
4. 单应用就选（或勾选多个）应用，点保存 / 批量套用
5. 目标应用从最近任务划掉重开生效

换过机型后如果尾巴还是旧的，清一次该应用的数据再看。

## 适配

- Root 管理器：KernelSU 或 APatch
- 架构：64 位
